================================================================================
                    三科目惯导系统 — 按键操作说明
================================================================================

【硬件按键对应】
  KEY_1 (S1)   =  P20_0   短按/长按(按住>1秒)
  KEY_2 (S2)   =  P20_1   短按/长按(按住>1秒)
  KEY_3 (S3)   =  P20_2   预留
  KEY_4 (S4)   =  P20_3   预留


================================================================================
一、普通模式 (开机默认)
================================================================================
  屏幕显示:
    Row 5:  M:normal   S:idle
    Row 6:  R:kemu1    P:kemu1
    Row 7:  (空)

  ┌────────┬────────────────────┬────────────────────┐
  │  按键   │       短按          │     长按(>1秒)      │
  ├────────┼────────────────────┼────────────────────┤
  │ KEY_1  │ 循环切换记录科目     │ 进入记录模式        │
  │        │ kemu1→kemu2→kemu3  │ 并立即开始记录      │
  ├────────┼────────────────────┼────────────────────┤
  │ KEY_2  │ 循环切换回放科目     │ 进入回放模式        │
  │        │ kemu1→kemu2→kemu3  │ (待机状态)          │
  └────────┴────────────────────┴────────────────────┘

  说明:
    - 开机后先在普通模式下选好要记录的科目(R:)和要回放的科目(P:)
    - 科目一(kemu1): 1段×10000点, 科目二(kemu2): 10段×2000点, 科目三(kemu3): 1段×400点


================================================================================
二、记录模式 (KEY_1 长按进入)
================================================================================
  屏幕显示:
    Row 5:  M:record   S:run
    Row 6:  R:kemu1    P:kemu1
    Row 7:  SEG: 0

  ┌────────┬────────────────────┬────────────────────┐
  │  按键   │       短按          │     长按(>1秒)      │
  ├────────┼────────────────────┼────────────────────┤
  │ KEY_1  │ 切换到下一段继续记录 │        --          │
  │        │ (段号+1,里程归零)   │                    │
  ├────────┼────────────────────┼────────────────────┤
  │ KEY_2  │ 清空当前段数据       │ 结束记录            │
  │        │ (里程归零,重新记)   │ 保存Flash → 回普通  │
  └────────┴────────────────────┴────────────────────┘

  状态说明:
    S:run  = ISR正在记录 (guandao_flag=1)
    SEG:N  = 当前段号

  典型操作:
    1. KEY_1长按 → 进入记录, 屏幕显示 S:run SEG:0
    2. 推车前进 → 每3cm自动记录一个偏航角, 屏幕 car_distances 递增
    3. 当前段记满 → 自动停止(不会溢出)
    4. KEY_1短按 → 切换到下一空段继续记录 (科目二最多10段)
    5. KEY_2短按 → 当前段数据清零,重新记录
    6. KEY_2长按 → 保存到Flash, 退出回普通模式

  注意事项:
    - 记录时推车即可, 不需要电机平衡
    - 段满后自动停止写入, 不会破坏已有数据
    - 科目二有10段, 每段2000点, 按KEY_1短按逐段记录
    - 科目一/三只有1段, KEY_1短按无效
    - 退出前一定用KEY_2长按保存, 否则断电数据丢失！


================================================================================
三、回放模式 (KEY_2 长按进入)
================================================================================
  屏幕显示:
    待机:  M:play     S:init    SEG:(不显示)
    平衡:  M:play     S:balance
    回放:  M:play     S:run     SEG: 0

  ┌────────┬────────────────────┬────────────────────┐
  │  按键   │       短按          │     长按(>1秒)      │
  ├────────┼────────────────────┼────────────────────┤
  │ KEY_1  │ 第1次: 进入平衡状态 │ 退出回放模式        │
  │        │ 第2次: 开始回放     │ 停车 → 回普通模式   │
  ├────────┼────────────────────┼────────────────────┤
  │ KEY_2  │        --          │        --          │
  └────────┴────────────────────┴────────────────────┘

  状态说明:
    S:init    = 待机, 等待KEY_1短按启动 (guandao_flag=0)
    S:balance = 平衡状态, 电机使能但不转向 (guandao_flag=3)
    S:run     = 回放中, 电机+转向全开 (guandao_flag=4)

  典型操作:
    1. KEY_2长按 → 进入回放, 屏幕显示 M:play S:init
    2. 把车放稳
    3. KEY_1短按第1次 → 进入平衡, 屏幕显示 S:balance
       (车自动平衡站立, 但不前进)
    4. KEY_1短按第2次 → 开始回放, 屏幕显示 S:run SEG:0
       (车每3cm读取一个偏航角, 自动转向行驶)
    5. 当前段回放完毕 → 自动跳下一段
    6. 所有段回放完毕 → 自动停车
    7. KEY_1长按 → 随时退出回放, 停车回普通模式

  注意事项:
    - 必须先在普通模式下选好回放科目(P:)
    - 回放前确保已有记录数据(segment_count>0), 否则不会动
    - 空段自动跳过
    - 平衡和回放阶段车必须放在水平地面上


================================================================================
四、屏幕显示完整说明
================================================================================
  Row 0:  R:  1.23  P:  4.56  Y: 78.90    (Roll/Pitch/Yaw 姿态角)
  Row 1:  GO: 1                            (启动标志 go_flag)
  Row 2:  12345  F:4                       (行驶距离car_distances + guandao_flag)
  Row 3:  (空)
  Row 4:  (空)
  Row 5:  M:normal   S:idle               (模式 Mode + 状态 State)
  Row 6:  R:kemu1    P:kemu2              (记录科目 + 回放科目)
  Row 7:  SEG: 0                           (段号, 仅记录/回放模式显示)

  guandao_flag (F:) 值:
    0 = 空闲(无ISR操作)
    1 = ISR记录中
    3 = 电机使能(仅平衡)
    4 = 电机+转向使能(回放行驶)


================================================================================
五、Flash 存储说明
================================================================================
  存储位置: Work Flash (0x14000000), sector 0
  布局:
    科目一: 页 0~19 (数据) + 页20 (段计数) = 42KB
    科目二: 页21~60 (数据) + 页61 (段计数) = 82KB
    科目三: 页62   (数据) + 页63 (段计数) =  2KB
    合计: 64页 / 128KB

  保存时机: 记录模式下 KEY_2 长按退出时自动保存
  加载时机: 开机 INIT() 后自动从Flash恢复全部三科目

  注意:
    - 记录结束后必须用KEY_2长按退出才能保存
    - 如果直接断电, 当次记录的数据会丢失
    - 已保存的数据下次开机自动恢复


================================================================================
六、操作流程速查
================================================================================

  [记录新路径]
    开机 → KEY_1短按选科目 → KEY_1长按进记录 → 推车记录
    → KEY_1短按切段(如需) → KEY_2长按保存退出

  [回放已有路径]
    开机 → KEY_2短按选科目 → KEY_2长按进回放
    → KEY_1短按(平衡) → KEY_1短按(回放) → 等待跑完
    → KEY_1长按退出

  [清空某段重录]
    记录模式中 → KEY_2短按清空当前段 → 重新推车记录

  [清除全部数据]
    普通模式下 → 暂未分配专用按键(可通过Flash工具擦除)
